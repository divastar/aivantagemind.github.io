# 3DDDesign

Static GitHub Pages site for **3DDDesign**.

## Purpose

3DDDesign is a design/business landing page for visual branding, static landing pages, creative direction, and client-focused design services.

## Files

- `index.html` — Plain HTML business landing page with SEO metadata.
- `styles.css` — Mobile-first responsive CSS, no frameworks.

## Deployment

Push these files to `aivyon/3dddesign` on the `main` branch. Enable GitHub Pages from **Settings → Pages → Deploy from a branch**, selecting `main` and `/root`.

## Domain notes

No final custom domain was provided. If you choose `3dddesign.com`, add a `CNAME` file containing that domain and configure DNS for GitHub Pages. Until then, the site can be served from `https://aivyon.github.io/3dddesign/` if deployed as a project page.
