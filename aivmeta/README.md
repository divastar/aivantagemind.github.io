# AIVMeta

Static GitHub Pages site for **AIVMeta** at `aivmeta.com`.

## Purpose

AIVMeta is an AI media identity for short videos, explainers, visual essays, and experimental educational content about emerging artificial intelligence.

## Files

- `index.html` — Plain HTML landing page with SEO and Open Graph metadata.
- `styles.css` — Mobile-first responsive CSS, no frameworks.
- `CNAME` — Custom domain for GitHub Pages.

## Deployment

Push these files to `aivyon/aivmeta` on the `main` branch. Enable GitHub Pages from **Settings → Pages → Deploy from a branch**, selecting `main` and `/root`.

## Domain notes

Set the custom domain to `aivmeta.com`. Configure apex GitHub Pages `A` records and optionally point `www` to `aivyon.github.io`.
