# PersenseAI

Static GitHub Pages site for **PersenseAI** at `persenseai.com`.

## Purpose

PersenseAI is a future-facing AI product/lab for visual agents, perception systems, multimodal reasoning, tracking diagnostics, and AI that senses and makes sense of the physical world.

## Files

- `index.html` — Plain HTML landing page with SEO metadata.
- `styles.css` — Mobile-first responsive CSS, no frameworks.
- `CNAME` — Custom domain for GitHub Pages.

## GitHub Pages deployment

1. Push these files to the `main` branch of `aivyon/persenseai`.
2. In GitHub, open **Settings → Pages**.
3. Set source to **Deploy from a branch**.
4. Choose branch `main` and folder `/root`.
5. Save.

## Domain notes

Add the custom domain `persenseai.com` in GitHub Pages. Configure DNS at the registrar with GitHub Pages apex `A` records and an optional `www` CNAME pointing to `aivyon.github.io`.
