# LearnWithLev

Static GitHub Pages site for **LearnWithLev**.

## Purpose

LearnWithLev is an educational site for math, probability, reasoning, and social learning content. The tone is friendly, visual, and accessible.

## Files

- `index.html` — Plain HTML educational landing page with SEO metadata.
- `styles.css` — Mobile-first responsive CSS, no frameworks.

## Deployment

Push these files to `aivyon/learnwithlev` on the `main` branch. Enable GitHub Pages from **Settings → Pages → Deploy from a branch**, selecting `main` and `/root`.

## Domain notes

No final custom domain was provided. If you choose `learnwithlev.com`, add a `CNAME` file containing that domain and configure DNS for GitHub Pages. Until then, the site can be served from `https://aivyon.github.io/learnwithlev/` if deployed as a project page.
