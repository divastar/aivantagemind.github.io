# KoriVision

Static GitHub Pages portfolio site for **Korin Lifshits**, Senior Computer Vision Engineer, at `korivision.com`.

## Purpose

KoriVision is a personal professional portfolio focused on computer vision engineering, tracking, ReID, 3D vision, optimization, evaluation, and production AI systems.

## Files

- `index.html` — Plain HTML portfolio landing page with SEO metadata.
- `styles.css` — Mobile-first responsive CSS, no frameworks.
- `CNAME` — Custom domain for GitHub Pages.

## Deployment

Push these files to `aivyon/korivision` on the `main` branch. Enable GitHub Pages from **Settings → Pages → Deploy from a branch**, selecting `main` and `/root`.

## Domain notes

Set the custom domain to `korivision.com`. Configure DNS for GitHub Pages at your registrar, including optional `www` forwarding or CNAME.
